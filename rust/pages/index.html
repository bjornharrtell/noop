Noop server

Your own Noop on a small Linux VPS: one Rust binary, SQLite, the web app, HTTPS by Caddy. Source and releases: github.com/bjornharrtell/noop.

1. Install

On a Debian or Ubuntu VPS (x86_64 or ARM, 1 GB RAM is plenty), with a DNS name pointing at it:

curl -fsSL https://bjornharrtell.github.io/noop/install.sh | sudo bash -s -- \
  --domain noop.example.com --email you@example.com --firewall
  • --domain: the name Caddy gets an HTTPS certificate for. On Hetzner the server's own name works, e.g. static.218.116.29.2.clients.your-server.de.
  • --email: who may sign in.
  • --firewall: allow only SSH, HTTP and HTTPS (leave it out on a server that runs other things).

2. First sign-in

Signing in takes three things: your email, a one-time code, and the code from an authenticator app.

  1. Bind your authenticator app (Google Authenticator, 1Password, Authy…). On the VPS: 
    sudo -u noop noop-server 2fa-setup
    Scan the QR code it shows, then type the 6-digit code the app shows.
  2. Open your Noop address (https://noop.example.com), enter your email and press Send code.
  3. Get the one-time code:
    • without email set up, on the VPS: 
      sudo -u noop noop-server login-code
    • or by email, once HUB_SMTP is set (below).
  4. Enter that code and the authenticator's current code. On a phone, add the page to the home screen and allow notifications.

Codes by email (optional)

Edit the settings with sudoedit /etc/noop/noop.env and set one line, for example with a Gmail app password:

HUB_SMTP={"host":"smtp.gmail.com","port":465,"user":"you@gmail.com","pass":"abcd efgh ijkl mnop","from":"Noop <you@gmail.com>"}

Port 465 is TLS, 587 is STARTTLS. Then:

sudo systemctl restart noop-server
sudo -u noop noop-server test-mail you@example.com

Update

curl -fsSL https://bjornharrtell.github.io/noop/install.sh | sudo bash

Replaces the server and the web app; settings (/etc/noop/noop.env) and data (/var/lib/noop) are kept. Nightly backups are in /var/lib/noop/backups.

Connect your machines

The machines that run your agents connect with the machine key, HUB_TOKEN in /etc/noop/noop.env, and the address https://noop.example.com.
